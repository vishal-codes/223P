Anatomy of a Class
The blueprint — nothing real exists yet

Core Idea

A class is a template

You define what data (attributes) and actions (methods) instances of that class will have. Think of it like a form — you design the form fields, not the filled-in answers.

class Student:
    # __init__ runs automatically when you create an object
    def __init__(self, name, grade):
        self.name  = name    # attribute: stores the name
        self.grade = grade   # attribute: stores the grade

    # a method: an action the object can perform
    def is_passing(self):
        return self.grade >= 60

    def greet(self):
        print(f"Hi, I am {self.name}!")
💡

self is a reference to the object itself. Every method must take it as the first parameter. You never pass it in manually — Python handles that.

⚠

Common mistake: Forgetting self inside a method. Writing name instead of self.name will cause a NameError.

Creating Objects
Instances — the real things built from the blueprint

Core Idea

An object is one filled-in copy

You call the class like a function to create an object. Each object has its own copy of the attributes but shares the same methods. You can create as many as you want.

# Create two separate Student objects
s1 = Student("Priya", 91)
s2 = Student("Jake", 55)

# Access attributes with dot notation
print(s1.name)          # "Priya"
print(s2.grade)         # 55

# Call methods
s1.greet()              # Hi, I am Priya!
print(s2.is_passing())  # False

# You can change attributes after creation
s2.grade = 65
print(s2.is_passing())  # True
✓

Remember: s1.name and s2.name are completely separate. Changing one does not affect the other. Each object owns its own data.

List Comprehensions
Build lists in one clean line

Core Idea

A compact for-loop that produces a list

The pattern is always: [expression for item in iterable if condition]. The if condition part is optional — use it only when you want to filter.

REGULAR LOOP

# Filter grades above 60
grades = [91, 78, 55, 83, 47]
high = []
for g in grades:
    if g >= 60:
        high.append(g)
# [91, 78, 83]

COMPREHENSION

# Same result, one line
grades = [91, 78, 55, 83, 47]



high = [g for g in grades
        if g >= 60]
# [91, 78, 83]
# Transform: square every number
squares = [x**2 for x in range(5)]
# [0, 1, 4, 9, 16]

# Filter: keep only even numbers
evens = [x for x in range(10) if x % 2 == 0]
# [0, 2, 4, 6, 8]

# Transform + filter at once
big_squares = [x**2 for x in range(10) if x > 5]
# [36, 49, 64, 81]

# Works on strings too
names = ["priya", "jake", "mia"]
upper = [n.upper() for n in names]
# ["PRIYA", "JAKE", "MIA"]
⚠

Avoid nesting too deep: A comprehension with two for-loops is fine, but three levels gets unreadable fast. If it's getting long, use a regular loop instead.

Classes + Comprehensions Together
Where both concepts click into place

Core Idea

Comprehensions work on lists of objects

You can store objects in a list and then use a comprehension to pull out attributes, filter by method results, or transform data across all of them in one line.

# List of objects
students = [
    Student("Priya", 91),
    Student("Jake", 55),
    Student("Mia",  73),
    Student("Leo",  48),
]

# Get all names
names = [s.name for s in students]
# ["Priya", "Jake", "Mia", "Leo"]

# Get names of students who are passing
passing = [s.name for s in students if s.is_passing()]
# ["Priya", "Mia"]

# Get all grades as a list
all_grades = [s.grade for s in students]
# [91, 55, 73, 48]

# Compute average using sum + len
avg = sum([s.grade for s in students]) / len(students)
# 66.75

Combined (Classes + Comprehensions)
